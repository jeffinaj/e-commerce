# 🛒 ShopKart - Modern E-Commerce Website

ShopKart is a responsive and modern e-commerce website built using HTML, CSS, JavaScript, and Bootstrap. The project provides a clean shopping experience with product listings, category sections, promotional offers, and an interactive cart system.

## 🚀 Features

- Modern and Responsive UI
- Bootstrap 5 Integration
- Attractive Hero Section
- Product Categories Section
- Best Selling Products Display
- Cashback Offer Banner
- Add to Cart Functionality
- Mobile-Friendly Design
- Clean and Organized Code Structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Bootstrap Icons

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/ecommerce-website.git
```

2. Navigate to the project folder

```bash
cd ecommerce-website
```

3. Open `index.html` in your browser

OR

Use VS Code Live Server:

```bash
Right Click → Open with Live Server
```
